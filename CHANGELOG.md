# Changelog

## 0.1.0 — unreleased alpha

- Shared C ABI for Gregorian, Borkowski Jalali, Islamic civil and Julian dates.
- Kotlin/JNI, Swift/C, Dart/FFI APIs with strict parsing and range validation.
- Controlled SwiftUI, Compose and Flutter month-grid examples.
- Runnable Kotlin Android, SwiftUI macOS/iOS and Flutter native demos.
- Flutter FFI source plugin automatically builds the target C engine.
- Shared 6,354-row Jalali year-boundary corpus in all three bindings.
- Exhaustive 12,007,879-day core checks, independent ICU oracle, pinned-reference
  oracle, malformed input and sanitizer checks.
- GitHub Actions builds, tests, Android instrumentation and source packaging.
- Explicit accuracy/platform contract; no claim of official annual certification.
